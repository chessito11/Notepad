# ATLAS Notepad

An installable, offline-first notepad for regular notes and construction field records. It runs as a Progressive Web App from GitHub Pages and does not require Android Studio.

## Features

- Regular Note, Checklist, Project Note, Daily Log, Materials, and Issue types
- Offline autosave using IndexedDB
- Search, type filters, project/job field, tags, and pinned notes
- Checklists and photo attachments
- Share text and print/save individual notes as PDF
- Visible Save, PDF, and Delete controls on phone and desktop
- Smooth touch scrolling through long notes
- Reliable opening of existing notes on installed Android and browser versions
- Punch-list item cards with unlimited per-item photos, completion, filtering, and reordering
- Full JSON backup and restore
- Responsive phone, tablet, and desktop layout
- Installable on Android from Chrome

## Install on Android

1. Open the GitHub Pages address in Chrome while connected to the internet.
2. Tap **Install app** when it appears, or use Chrome's menu and choose **Add to Home screen**.
3. Open ATLAS Notepad once from the new home-screen icon.
4. It will continue working without internet.

Notes and photos are stored only in that browser/device. Use **Export backup** regularly and before clearing browser data, changing phones, or uninstalling the app.

## GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
