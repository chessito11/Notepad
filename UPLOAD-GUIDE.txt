ATLAS NOTEPAD — GITHUB UPLOAD

1. Create a new PUBLIC GitHub repository named: ATLAS-Notepad
2. Open the new repository and choose: Add file > Upload files
3. Extract this ZIP on your computer first.
4. Upload the CONTENTS inside the ATLAS-Notepad-PWA folder.
   Important: index.html must appear at the top level of the repository.
5. Commit the uploaded files.
6. Open: Settings > Pages
7. Under Build and deployment choose: Deploy from a branch
8. Select branch: main
9. Select folder: / (root)
10. Click Save.

GitHub will provide the website address after deployment finishes.

UPDATING AN EXISTING ATLAS-NOTEPAD REPOSITORY

Upload the new files and replace the older files when GitHub asks. After the
commit finishes, GitHub Pages will rebuild automatically. Open the app while
online and refresh once so the new offline files are installed.

ANDROID OFFLINE INSTALL

1. Open the GitHub Pages website in Chrome on the Android tablet or phone.
2. Tap Install app if the button appears.
3. Otherwise use Chrome's three-dot menu > Add to Home screen.
4. Open ATLAS Notepad once from the new icon while online.
5. After that, notes and the app work without internet.

Notes are stored on that device. Use Export backup regularly and before
clearing Chrome data, changing devices, or uninstalling the app.
